# RelayOps AI product brief

## Mode
Operate. The operator must recognize state, evidence, exceptions, and next safe action within seconds.

## User and task
A municipal dispatcher receives a messy resident report, verifies jurisdiction and evidence, and decides whether a prebuilt crew route is safe to release. The interface must make unresolved facts impossible to miss.

## Non-negotiables
Synthetic data only; deterministic offline baseline; no automatic dispatch; no fabricated outcome; visible uncertainty; keyboard and mobile access; no model credential required.
